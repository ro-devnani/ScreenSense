# Orange-Tip Pen Tracker — Dual Camera System

A dual-camera computer vision system that tracks the tip of an orange pen drawn on a black-background plane in real time. Uses HSV color segmentation, confidence-weighted sensor fusion, and a Kalman filter to produce smooth, reliable 2D stroke coordinates even under occlusion or poor lighting.

## Overview

### Physical Setup

```
  CAM1 (index 0)              CAM2 (index 1)
       📷──────────────────────────📷
        \                          /
         \        OVERLAP          /
          \        ZONE           /
           \                    /
            \                  /
  ┌──────────────────────────────────┐
  │                                  │  ← Black-background plane
  │         (drawing surface)        │     perpendicular to ground
  └──────────────────────────────────┘
```

Both cameras are mounted at the top corners of the plane, angled inward at roughly 45–60°. The black background maximises contrast for the orange pen tip, making HSV segmentation extremely reliable.

### Data Flow

```
Camera 1 frame ──► undistort ──► HSV mask ──► centroid ──► homography ──► plane pt₁, conf₁ ──┐
                                                                                                ├──► weighted fusion ──► Kalman filter ──► (x, y)
Camera 2 frame ──► undistort ──► HSV mask ──► centroid ──► homography ──► plane pt₂, conf₂ ──┘
```

## Hardware Requirements

| Component | Recommendation | Notes |
|---|---|---|
| Cameras | 2× USB webcams, 1080p minimum | Logitech C920 or equivalent; higher FPS = smoother tracking |
| Drawing surface | Matte black foam board or blackout fabric | Gloss causes specular highlights that confuse HSV detection |
| Pen | Any pen with a bright orange cap or orange tip ring | Fluorescent orange works best; avoid metallic orange |
| Mounting | Two adjustable camera arms fixed to a horizontal rail | Stability is critical; vibration introduces false motion |
| Lighting | Diffuse overhead white light | Avoid direct sunlight — it shifts the hue toward yellow |

### Why a Black Background Specifically

A pure black background (HSV: V ≈ 0) falls entirely outside any reasonable orange HSV range. This means:

- After `cv2.inRange()`, background pixels are guaranteed to be **black (0)** in the mask
- The orange tip pixels are guaranteed to be **white (255)** in the mask
- No morphological tricks or adaptive thresholding are needed to separate foreground from background
- Confidence scores are more reliable because blob size variation comes only from the tip, not from misdetections

## Configuration

All parameters live in `config.yaml`. Edit this file before running anything else.

```yaml
# config.yaml

cameras:
  cam1_index: 0          # OS index of the first camera (top-left)
  cam2_index: 1          # OS index of the second camera (top-right)
  width: 1280            # Capture resolution width  (must match calibration)
  height: 720            # Capture resolution height (must match calibration)
  fps: 60                # Target frames per second; use highest your camera supports

plane:
  # Real-world dimensions of the drawing surface in millimetres
  width_mm: 600
  height_mm: 400
  # The four corner points of the plane in real-world coords (mm), ordered:
  # top-left, top-right, bottom-right, bottom-left
  corners_mm:
    - [0,   0  ]
    - [600, 0  ]
    - [600, 400]
    - [0,   400]

detection:
  # HSV range for the orange pen tip — run tools/hsv_tuner.py to find these
  hsv_lower: [5,  160, 100]   # [H_min, S_min, V_min]
  hsv_upper: [22, 255, 255]   # [H_max, S_max, V_max]

  # Minimum contour area in pixels² to be considered a valid detection
  # Too low = noise gets through. Too high = tip not detected when partially occluded.
  min_area: 20

  # Area in pixels² that represents a "perfect" fully-visible tip.
  # Used to normalise confidence scores to 0.0–1.0.
  ideal_area: 300

  # Morphological kernel size for noise removal (must be odd)
  morph_kernel_size: 5

  # Optional: restrict detection to a sub-region of the frame to save CPU.
  # [x_start, y_start, x_end, y_end] in pixels. Set to null to use full frame.
  roi_cam1: null
  roi_cam2: null

fusion:
  # When only one camera sees the tip, its confidence is multiplied by this
  # penalty (because a single-camera estimate is less reliable).
  single_camera_penalty: 0.6

  # Detections below this confidence threshold are treated as "lost"
  # and not passed to the Kalman filter as measurements.
  min_confidence: 0.2

kalman:
  # How much to trust the motion model vs the measurement.
  # Higher process_noise  = filter trusts measurements more  (jittery but responsive)
  # Lower  process_noise  = filter trusts model more          (smooth but lags)
  process_noise: 0.01

  # How much noise to expect in the fused measurements.
  # Higher measurement_noise = filter relies more on prediction (smoother under occlusion)
  # Lower  measurement_noise = filter snaps to measurements quickly
  measurement_noise: 0.1

output:
  # Whether to display a live debug window showing masks and detections
  show_debug: true

  # Whether to save stroke points to output/strokes.json
  save_strokes: true

  # Minimum movement in mm before a new point is recorded (reduces duplicate points)
  min_move_mm: 1.0
```

## Module Reference

### calibrate.py

Run this **once** before using the tracker. It computes the undistortion parameters and homography matrix for each camera.

```python
# calibration/calibrate.py
"""
Calibration script for both cameras.

Usage:
    python calibration/calibrate.py --cam 0 --out calibration/cam1_calibration.npz
    python calibration/calibrate.py --cam 1 --out calibration/cam2_calibration.npz

Steps performed:
    1. Capture frames from the specified camera.
    2. Detect a printed checkerboard held against the plane in various positions.
    3. Compute intrinsic camera matrix (mtx) and distortion coefficients (dist).
    4. Ask the user to click the four plane corners to compute the homography H.
    5. Save mtx, dist, and H to the output .npz file.
"""

import cv2
import numpy as np
import argparse
import yaml

# ── Config ──────────────────────────────────────────────────────────────────

CHECKERBOARD = (9, 6)       # inner corner count of your printed checkerboard
SQUARE_SIZE  = 25.0         # physical size of each square in mm
MIN_CAPTURES = 20           # minimum valid checkerboard captures required

# ── Intrinsic calibration ────────────────────────────────────────────────────

def collect_calibration_frames(cam_index, width, height):
    """
    Opens the camera and waits for the user to press SPACE to capture a
    checkerboard frame. Presses Q to finish collecting and proceed to calibration.

    Returns:
        obj_points: list of 3D checkerboard corner coordinates (in mm)
        img_points: list of corresponding 2D pixel coordinates per frame
        frame_size: (width, height) tuple
    """
    cap = cv2.VideoCapture(cam_index)
    cap.set(cv2.CAP_PROP_FRAME_WIDTH,  width)
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)

    obj_p = np.zeros((CHECKERBOARD[0] * CHECKERBOARD[1], 3), np.float32)
    obj_p[:, :2] = np.mgrid[0:CHECKERBOARD[0],
                             0:CHECKERBOARD[1]].T.reshape(-1, 2) * SQUARE_SIZE

    obj_points = []
    img_points = []
    captured   = 0

    print(f"[CAM {cam_index}] Hold the checkerboard flat against the plane.")
    print("Press SPACE to capture, Q when done (need at least", MIN_CAPTURES, "captures).")

    while True:
        ret, frame = cap.read()
        if not ret:
            continue

        gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
        found, corners = cv2.findChessboardCorners(gray, CHECKERBOARD, None)

        display = frame.copy()
        if found:
            cv2.drawChessboardCorners(display, CHECKERBOARD, corners, found)
            cv2.putText(display, f"Found! Captures: {captured}", (20, 40),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 255, 0), 2)
        else:
            cv2.putText(display, f"No board detected. Captures: {captured}", (20, 40),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.8, (0, 0, 255), 2)

        cv2.imshow(f"Calibration — Camera {cam_index}", display)
        key = cv2.waitKey(1) & 0xFF

        if key == ord(' ') and found:
            # Refine corners to sub-pixel accuracy
            criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
            corners_refined = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1), criteria)
            obj_points.append(obj_p)
            img_points.append(corners_refined)
            captured += 1
            print(f"  Captured frame {captured}")

        elif key == ord('q'):
            if captured < MIN_CAPTURES:
                print(f"WARNING: Only {captured} captures. Need {MIN_CAPTURES} for reliable calibration.")
            break

    cap.release()
    cv2.destroyAllWindows()
    return obj_points, img_points, (width, height)


def compute_intrinsics(obj_points, img_points, frame_size):
    """
    Compute the camera matrix and distortion coefficients.

    Returns:
        mtx  : 3×3 camera intrinsic matrix
        dist : distortion coefficients array (k1, k2, p1, p2, k3)
        rms  : reprojection RMS error (should be < 0.5 for good calibration)
    """
    rms, mtx, dist, _, _ = cv2.calibrateCamera(
        obj_points, img_points, frame_size, None, None
    )
    print(f"  Intrinsic calibration RMS reprojection error: {rms:.4f} px")
    if rms > 1.0:
        print("  WARNING: RMS > 1.0 — consider recapturing with better coverage of the frame.")
    return mtx, dist, rms

# ── Homography calibration ────────────────────────────────────────────────────

clicked_points = []

def _mouse_callback(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        clicked_points.append((x, y))
        print(f"  Clicked point {len(clicked_points)}: ({x}, {y})")

def compute_homography(cam_index, mtx, dist, width, height, plane_corners_mm):
    """
    Displays a live undistorted frame and asks the user to click the four
    corners of the plane in order: top-left, top-right, bottom-right, bottom-left.

    Returns:
        H: 3×3 homography matrix mapping pixel coords → plane mm coords
    """
    global clicked_points
    clicked_points = []

    cap = cv2.VideoCapture(cam_index)
    cap.set(cv2.CAP_PROP_FRAME_WIDTH,  width)
    cap.set(cv2.CAP_PROP_FRAME_HEIGHT, height)

    cv2.namedWindow(f"Homography — Camera {cam_index}")
    cv2.setMouseCallback(f"Homography — Camera {cam_index}", _mouse_callback)

    print(f"\n[CAM {cam_index}] Click the four corners of the plane:")
    print("  Order: top-left → top-right → bottom-right → bottom-left")

    while len(clicked_points) < 4:
        ret, frame = cap.read()
        if not ret:
            continue

        # Show undistorted frame so clicks are in undistorted pixel space
        undistorted = cv2.undistort(frame, mtx, dist)
        display     = undistorted.copy()

        for i, pt in enumerate(clicked_points):
            cv2.circle(display, pt, 6, (0, 255, 255), -1)
            cv2.putText(display, str(i + 1), (pt[0] + 8, pt[1] - 8),
                        cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 255, 255), 2)

        remaining = 4 - len(clicked_points)
        cv2.putText(display, f"Click {remaining} more corner(s)", (20, 40),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.8, (255, 255, 255), 2)
        cv2.imshow(f"Homography — Camera {cam_index}", display)
        cv2.waitKey(1)

    cap.release()
    cv2.destroyAllWindows()

    pixel_pts = np.array(clicked_points,   dtype=np.float32)
    plane_pts = np.array(plane_corners_mm, dtype=np.float32)

    # findHomography: maps FROM pixel coords TO plane mm coords
    H, mask = cv2.findHomography(pixel_pts, plane_pts, cv2.RANSAC, 5.0)
    print(f"  Homography computed. Inlier ratio: {mask.sum()}/{len(mask)}")
    return H

# ── Entry point ───────────────────────────────────────────────────────────────

if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--cam",  type=int, required=True, help="Camera index (0 or 1)")
    parser.add_argument("--out",  type=str, required=True, help="Output .npz path")
    parser.add_argument("--config", type=str, default="config.yaml")
    args = parser.parse_args()

    with open(args.config) as f:
        cfg = yaml.safe_load(f)

    W = cfg["cameras"]["width"]
    H_res = cfg["cameras"]["height"]
    corners = cfg["plane"]["corners_mm"]

    print(f"\n=== Step 1: Intrinsic calibration (Camera {args.cam}) ===")
    obj_pts, img_pts, fsize = collect_calibration_frames(args.cam, W, H_res)
    mtx, dist, rms = compute_intrinsics(obj_pts, img_pts, fsize)

    print(f"\n=== Step 2: Homography calibration (Camera {args.cam}) ===")
    H_mat = compute_homography(args.cam, mtx, dist, W, H_res, corners)

    np.savez(args.out, mtx=mtx, dist=dist, H=H_mat, rms=rms)
    print(f"\nCalibration saved to {args.out}")
```

### detect.py

The detection module. For each camera frame it:
1. Converts BGR → HSV
2. Applies an orange HSV threshold to produce the binary mask
3. Cleans the mask with morphological operations
4. Finds the largest remaining blob
5. Returns the blob's centroid in pixel space and a confidence score

```python
# src/detect.py

import cv2
import numpy as np
from dataclasses import dataclass
from typing import Optional, Tuple


@dataclass
class Detection:
    """
    Result of a single-camera detection attempt.

    Attributes:
        pixel_point : (u, v) in undistorted pixel space, or None if not found
        confidence  : float in [0.0, 1.0] — 0.0 = not found, 1.0 = ideal blob size
        mask        : the binary HSV mask (for debugging / display)
        area        : contour area of the detected blob in pixels²
    """
    pixel_point : Optional[Tuple[float, float]]
    confidence  : float
    mask        : np.ndarray
    area        : float


class OrangeTipDetector:
    """
    Detects an orange pen tip against a black background using HSV thresholding.

    The black background is key: V (value/brightness) near 0 means background
    pixels will never satisfy the V_min constraint in the orange range, giving
    a clean binary separation with no extra background removal needed.

    Parameters
    ----------
    hsv_lower    : (H_min, S_min, V_min) — lower bound of the orange HSV range
    hsv_upper    : (H_max, S_max, V_max) — upper bound of the orange HSV range
    min_area     : minimum blob area in px² to accept as a real detection
    ideal_area   : blob area in px² considered "fully visible" (used for confidence)
    kernel_size  : size of the morphological structuring element (must be odd)
    roi          : optional (x0, y0, x1, y1) crop rectangle to speed up processing
    """

    def __init__(
        self,
        hsv_lower    : Tuple[int, int, int] = (5,  160, 100),
        hsv_upper    : Tuple[int, int, int] = (22, 255, 255),
        min_area     : float = 20.0,
        ideal_area   : float = 300.0,
        kernel_size  : int   = 5,
        roi          : Optional[Tuple[int, int, int, int]] = None,
    ):
        self.lower       = np.array(hsv_lower, dtype=np.uint8)
        self.upper       = np.array(hsv_upper, dtype=np.uint8)
        self.min_area    = min_area
        self.ideal_area  = ideal_area
        self.roi         = roi

        # Elliptical kernel — better than rectangular for roughly circular blobs
        self.kernel = cv2.getStructuringElement(
            cv2.MORPH_ELLIPSE, (kernel_size, kernel_size)
        )

    def detect(self, frame: np.ndarray) -> Detection:
        """
        Run detection on a single undistorted BGR frame.

        Returns a Detection object. If no valid blob is found, pixel_point is
        None and confidence is 0.0, but mask is still returned for debugging.
        """
        # ── Step 1: Optionally crop to ROI ───────────────────────────────────
        if self.roi is not None:
            x0, y0, x1, y1 = self.roi
            region = frame[y0:y1, x0:x1]
            roi_offset = (x0, y0)
        else:
            region     = frame
            roi_offset = (0, 0)

        # ── Step 2: BGR → HSV ─────────────────────────────────────────────────
        # HSV separates hue (color identity) from saturation and brightness.
        # This makes the orange range consistent across different lighting levels
        # as long as the hue doesn't shift — which is why you tune S and V
        # minimums rather than relying on exact brightness values.
        hsv = cv2.cvtColor(region, cv2.COLOR_BGR2HSV)

        # ── Step 3: Threshold ─────────────────────────────────────────────────
        # inRange produces a binary image:
        #   white (255) = pixel falls within [lower, upper] in all three channels
        #   black (0)   = pixel is outside the range
        # Against a black background (V ≈ 0), background pixels always fail the
        # V_min constraint, so they are always black in the mask.
        mask = cv2.inRange(hsv, self.lower, self.upper)

        # ── Step 4: Morphological cleanup ─────────────────────────────────────
        # OPEN  = erosion then dilation: removes isolated white speckles
        #         that are smaller than the kernel. Eliminates salt noise.
        # CLOSE = dilation then erosion: fills small black holes inside white blobs.
        #         Handles cases where part of the tip is slightly under-exposed.
        mask = cv2.morphologyEx(mask, cv2.MORPH_OPEN,  self.kernel)
        mask = cv2.morphologyEx(mask, cv2.MORPH_CLOSE, self.kernel)

        # ── Step 5: Find blobs ────────────────────────────────────────────────
        # RETR_EXTERNAL: only outer contours (no nested contours needed here)
        # CHAIN_APPROX_SIMPLE: compress horizontal/vertical/diagonal runs to
        #                      endpoints only — saves memory on large contours
        contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        if not contours:
            return Detection(pixel_point=None, confidence=0.0, mask=mask, area=0.0)

        # Pick the largest blob — the pen tip should always be the dominant
        # orange object in the frame when using a black background
        best   = max(contours, key=cv2.contourArea)
        area   = cv2.contourArea(best)

        if area < self.min_area:
            # Blob exists but is too small — likely a reflection or noise artifact
            return Detection(pixel_point=None, confidence=0.0, mask=mask, area=area)

        # ── Step 6: Compute centroid ──────────────────────────────────────────
        # Image moments give us the center of mass of the white blob.
        # This is more accurate than the bounding box center for irregular shapes.
        M  = cv2.moments(best)
        cx = M["m10"] / M["m00"]   # x centroid in ROI pixel space
        cy = M["m01"] / M["m00"]   # y centroid in ROI pixel space

        # ── Step 7: Offset back to full-frame pixel space ─────────────────────
        full_cx = cx + roi_offset[0]
        full_cy = cy + roi_offset[1]

        # ── Step 8: Confidence score ──────────────────────────────────────────
        # Ratio of detected area to ideal area, clamped to [0, 1].
        # A partially occluded tip has a smaller blob → lower confidence.
        # The Kalman filter and fusion step will weight this estimate accordingly.
        confidence = float(min(area / self.ideal_area, 1.0))

        return Detection(
            pixel_point=(full_cx, full_cy),
            confidence=confidence,
            mask=mask,
            area=area,
        )

    @classmethod
    def from_config(cls, cfg: dict, cam_key: str = None) -> "OrangeTipDetector":
        """Construct a detector from a parsed config.yaml dict."""
        d   = cfg["detection"]
        roi = d.get(f"roi_{cam_key}") if cam_key else None
        return cls(
            hsv_lower   = tuple(d["hsv_lower"]),
            hsv_upper   = tuple(d["hsv_upper"]),
            min_area    = d["min_area"],
            ideal_area  = d["ideal_area"],
            kernel_size = d["morph_kernel_size"],
            roi         = tuple(roi) if roi else None,
        )
```

### fuse.py

Takes the two plane-coordinate estimates and their confidence scores, and merges them into one weighted estimate.

```python
# src/fuse.py

from dataclasses import dataclass
from typing import Optional, Tuple
import numpy as np


@dataclass
class FusedEstimate:
    """
    Result of fusing both camera detections into one plane coordinate.

    Attributes:
        plane_point : (x, y) in plane mm coords, or None if both cameras lost the tip
        confidence  : combined confidence — lower when only one camera sees the tip,
                      lowest when both cameras lost it
        source      : "both" | "cam1_only" | "cam2_only" | "lost"
    """
    plane_point : Optional[Tuple[float, float]]
    confidence  : float
    source      : str


class SensorFuser:
    """
    Confidence-weighted fusion of two independent camera estimates.

    When both cameras see the tip, their estimates are averaged weighted by
    confidence. When only one camera sees it, that estimate is used with a
    penalty applied (because a single viewpoint is less reliable).

    Parameters
    ----------
    single_camera_penalty : multiplier on confidence when only one camera detects
    min_confidence        : detections below this are treated as "not found"
    """

    def __init__(self, single_camera_penalty: float = 0.6, min_confidence: float = 0.2):
        self.penalty        = single_camera_penalty
        self.min_confidence = min_confidence

    def fuse(
        self,
        pt1  : Optional[Tuple[float, float]], conf1: float,
        pt2  : Optional[Tuple[float, float]], conf2: float,
    ) -> FusedEstimate:
        """
        Fuse two camera estimates.

        Parameters
        ----------
        pt1, conf1 : plane point and confidence from camera 1 (None if not detected)
        pt2, conf2 : plane point and confidence from camera 2 (None if not detected)

        Returns
        -------
        FusedEstimate with merged plane_point, combined confidence, and source tag.
        """
        # Apply minimum confidence threshold — treat weak detections as "not found"
        if conf1 < self.min_confidence:
            pt1, conf1 = None, 0.0
        if conf2 < self.min_confidence:
            pt2, conf2 = None, 0.0

        # ── Both lost ─────────────────────────────────────────────────────────
        if pt1 is None and pt2 is None:
            return FusedEstimate(plane_point=None, confidence=0.0, source="lost")

        # ── Only camera 2 sees the tip ────────────────────────────────────────
        if pt1 is None:
            return FusedEstimate(
                plane_point=pt2,
                confidence=conf2 * self.penalty,
                source="cam2_only",
            )

        # ── Only camera 1 sees the tip ────────────────────────────────────────
        if pt2 is None:
            return FusedEstimate(
                plane_point=pt1,
                confidence=conf1 * self.penalty,
                source="cam1_only",
            )

        # ── Both cameras see the tip — weighted average ───────────────────────
        # The point closer to "ideal" blob size gets more weight.
        # Example: conf1=0.9, conf2=0.4 → pt1 gets ~69% of the weight.
        total = conf1 + conf2
        x     = (pt1[0] * conf1 + pt2[0] * conf2) / total
        y     = (pt1[1] * conf1 + pt2[1] * conf2) / total

        # Combined confidence: mean of both, never exceeds 1.0
        combined_conf = min((conf1 + conf2) / 2.0, 1.0)

        return FusedEstimate(
            plane_point=(x, y),
            confidence=combined_conf,
            source="both",
        )

    @classmethod
    def from_config(cls, cfg: dict) -> "SensorFuser":
        f = cfg["fusion"]
        return cls(
            single_camera_penalty=f["single_camera_penalty"],
            min_confidence=f["min_confidence"],
        )
```

### kalman.py

A 4-state Kalman filter tracking `[x, y, vx, vy]` on the plane. When the pen is occluded and no measurement arrives, it uses the velocity state to predict forward so the tracked point doesn't freeze or jump.

```python
# src/kalman.py

import cv2
import numpy as np
from typing import Optional, Tuple


class PenKalmanFilter:
    """
    2D Kalman filter for smoothing pen tip position on the plane.

    State vector : [x, y, vx, vy]  (position and velocity in plane mm coords)
    Measurement  : [x, y]           (fused plane coordinate from SensorFuser)

    Behaviour
    ---------
    - When a measurement arrives above min_confidence: filter corrects state
    - When measurement is missing (occluded): filter predicts using velocity
    - Velocity state allows the filter to coast through short occlusions instead
      of freezing the last known position

    Parameters
    ----------
    process_noise     : trust the motion model less (higher = more responsive,
                        lower = smoother trajectory during fast movement)
    measurement_noise : trust measurements less (higher = smoother under noise,
                        lower = snaps to measurements aggressively)
    """

    def __init__(self, process_noise: float = 0.01, measurement_noise: float = 0.1):
        # 4 state variables [x, y, vx, vy], 2 measurement variables [x, y]
        self.kf = cv2.KalmanFilter(4, 2)

        # State transition matrix (constant-velocity model):
        # x_new  = x  + vx*dt   (dt = 1 frame, absorbed into the matrix)
        # y_new  = y  + vy*dt
        # vx_new = vx
        # vy_new = vy
        self.kf.transitionMatrix = np.array([
            [1, 0, 1, 0],
            [0, 1, 0, 1],
            [0, 0, 1, 0],
            [0, 0, 0, 1],
        ], dtype=np.float32)

        # Measurement matrix: we only observe x and y directly, not velocity
        self.kf.measurementMatrix = np.array([
            [1, 0, 0, 0],
            [0, 1, 0, 0],
        ], dtype=np.float32)

        # Process noise covariance: uncertainty in the motion model
        # Scale the velocity entries slightly higher — velocity is harder to predict
        self.kf.processNoiseCov = np.diag([
            process_noise,
            process_noise,
            process_noise * 2,
            process_noise * 2,
        ]).astype(np.float32)

        # Measurement noise covariance: uncertainty in HSV centroid measurements
        self.kf.measurementNoiseCov = np.eye(2, dtype=np.float32) * measurement_noise

        # Initial error covariance: high uncertainty before first measurement
        self.kf.errorCovPost = np.eye(4, dtype=np.float32) * 1.0

        self._initialized = False

    def update(
        self,
        measurement: Optional[Tuple[float, float]],
        confidence: float,
        min_confidence: float = 0.2,
    ) -> Tuple[float, float]:
        """
        Feed one fused measurement into the filter and return the smoothed estimate.

        Parameters
        ----------
        measurement    : (x, y) in plane mm coords, or None if pen not detected
        confidence     : fused confidence [0, 1]
        min_confidence : confidence threshold below which measurement is ignored

        Returns
        -------
        (x, y) smoothed plane coordinate — always a valid point once initialized
        """
        if measurement is not None and not self._initialized:
            # Seed the filter state with the first valid measurement
            self.kf.statePost = np.array(
                [[measurement[0]], [measurement[1]], [0.0], [0.0]],
                dtype=np.float32
            )
            self._initialized = True

        if not self._initialized:
            # No measurement ever — return origin as placeholder
            return (0.0, 0.0)

        # ── Predict step ──────────────────────────────────────────────────────
        # Advances the state by one time step using the transition matrix.
        # This MUST be called every frame, even when there is no measurement.
        predicted = self.kf.predict()

        # ── Correct step ──────────────────────────────────────────────────────
        if measurement is not None and confidence >= min_confidence:
            # Scale measurement noise inversely with confidence:
            # high confidence → trust measurement more (smaller noise)
            # low  confidence → trust prediction more (larger noise)
            noise_scale = 1.0 + (1.0 - confidence) * 5.0
            self.kf.measurementNoiseCov = (
                np.eye(2, dtype=np.float32)
                * self.kf.measurementNoiseCov[0, 0]
                * noise_scale
            )

            meas_array = np.array(
                [[measurement[0]], [measurement[1]]], dtype=np.float32
            )
            corrected = self.kf.correct(meas_array)
            x, y = float(corrected[0]), float(corrected[1])
        else:
            # No valid measurement — use pure prediction (coasting)
            x, y = float(predicted[0]), float(predicted[1])

        return (x, y)

    def reset(self):
        """Reset the filter state — call this when tracking resumes after a long gap."""
        self.kf.errorCovPost = np.eye(4, dtype=np.float32) * 1.0
        self._initialized    = False

    @classmethod
    def from_config(cls, cfg: dict) -> "PenKalmanFilter":
        k = cfg["kalman"]
        return cls(
            process_noise=k["process_noise"],
            measurement_noise=k["measurement_noise"],
        )
```

### tracker.py

The main loop. Opens both cameras, loads calibration data, runs detection → mapping → fusion → Kalman every frame, and optionally displays a debug view and writes strokes to disk.

```python
# src/tracker.py

import cv2
import numpy as np
import yaml
import json
import time
from pathlib import Path

from detect import OrangeTipDetector, Detection
from fuse   import SensorFuser
from kalman import PenKalmanFilter
from utils  import (
    load_calibration,
    map_to_plane,
    draw_debug_overlay,
    StrokeRecorder,
)


def run(config_path: str = "config.yaml"):
    # ── Load config ───────────────────────────────────────────────────────────
    with open(config_path) as f:
        cfg = yaml.safe_load(f)

    cam_cfg    = cfg["cameras"]
    out_cfg    = cfg["output"]

    # ── Load calibration data ─────────────────────────────────────────────────
    # Each .npz contains: mtx (camera matrix), dist (distortion), H (homography)
    cal1 = load_calibration("calibration/cam1_calibration.npz")
    cal2 = load_calibration("calibration/cam2_calibration.npz")

    # ── Build pipeline components ─────────────────────────────────────────────
    detector1 = OrangeTipDetector.from_config(cfg, cam_key="cam1")
    detector2 = OrangeTipDetector.from_config(cfg, cam_key="cam2")
    fuser     = SensorFuser.from_config(cfg)
    kalman    = PenKalmanFilter.from_config(cfg)
    recorder  = StrokeRecorder(
        min_move_mm=out_cfg["min_move_mm"],
        enabled=out_cfg["save_strokes"],
    )

    # ── Open cameras ─────────────────────────────────────────────────────────
    cap1 = cv2.VideoCapture(cam_cfg["cam1_index"])
    cap2 = cv2.VideoCapture(cam_cfg["cam2_index"])

    for cap in (cap1, cap2):
        cap.set(cv2.CAP_PROP_FRAME_WIDTH,  cam_cfg["width"])
        cap.set(cv2.CAP_PROP_FRAME_HEIGHT, cam_cfg["height"])
        cap.set(cv2.CAP_PROP_FPS,          cam_cfg["fps"])
        # Disable auto-exposure if your camera supports it — prevents hue drift
        cap.set(cv2.CAP_PROP_AUTO_EXPOSURE, 0.25)

    print("Tracker running. Press Q to quit, S to save current stroke.")

    prev_time = time.time()

    while True:
        # ── Capture ───────────────────────────────────────────────────────────
        ret1, frame1 = cap1.read()
        ret2, frame2 = cap2.read()

        if not ret1 or not ret2:
            print("WARNING: Frame capture failed — skipping frame.")
            continue

        # ── Undistort ─────────────────────────────────────────────────────────
        # Removes lens barrel/pincushion distortion using the intrinsic
        # calibration data. Must be done before detection so pixel coordinates
        # correspond to the same geometric space as the homography.
        frame1 = cv2.undistort(frame1, cal1["mtx"], cal1["dist"])
        frame2 = cv2.undistort(frame2, cal2["mtx"], cal2["dist"])

        # ── Detect ────────────────────────────────────────────────────────────
        det1: Detection = detector1.detect(frame1)
        det2: Detection = detector2.detect(frame2)

        # ── Map pixel → plane coords ──────────────────────────────────────────
        # Applies the homography to convert each detected pixel centroid into
        # real-world plane coordinates (mm from top-left corner of plane).
        pt1 = map_to_plane(det1.pixel_point, cal1["H"]) if det1.pixel_point else None
        pt2 = map_to_plane(det2.pixel_point, cal2["H"]) if det2.pixel_point else None

        # ── Fuse ──────────────────────────────────────────────────────────────
        fused = fuser.fuse(pt1, det1.confidence, pt2, det2.confidence)

        # ── Kalman smooth ─────────────────────────────────────────────────────
        x, y = kalman.update(
            measurement    = fused.plane_point,
            confidence     = fused.confidence,
            min_confidence = cfg["fusion"]["min_confidence"],
        )

        # ── Record stroke ─────────────────────────────────────────────────────
        if fused.source != "lost":
            recorder.add_point(x, y)

        # ── FPS counter ───────────────────────────────────────────────────────
        now      = time.time()
        fps      = 1.0 / max(now - prev_time, 1e-6)
        prev_time = now

        # ── Debug display ─────────────────────────────────────────────────────
        if out_cfg["show_debug"]:
            debug = draw_debug_overlay(
                frame1=frame1, frame2=frame2,
                det1=det1,     det2=det2,
                pt1=pt1,       pt2=pt2,
                fused=fused,   smoothed=(x, y),
                fps=fps,
            )
            cv2.imshow("Pen Tracker — Debug", debug)

        # ── Key handling ──────────────────────────────────────────────────────
        key = cv2.waitKey(1) & 0xFF
        if key == ord('q'):
            break
        elif key == ord('s'):
            recorder.save_stroke()
            print(f"Stroke saved ({len(recorder.current_stroke)} points)")

    # ── Cleanup ───────────────────────────────────────────────────────────────
    cap1.release()
    cap2.release()
    cv2.destroyAllWindows()

    if out_cfg["save_strokes"]:
        recorder.flush("output/strokes.json")
        print("All strokes written to output/strokes.json")


if __name__ == "__main__":
    run()
```

# src/utils.py

import cv2
import numpy as np
import json
import math
from pathlib import Path
from typing import Optional, Tuple


# ── Calibration I/O ──────────────────────────────────────────────────────────

def load_calibration(path: str) -> dict:
    """
    Load a calibration .npz file saved by calibrate.py.

    Returns a dict with keys: mtx, dist, H, rms
    """
    data = np.load(path)
    return {
        "mtx"  : data["mtx"],
        "dist" : data["dist"],
        "H"    : data["H"],
        "rms"  : float(data["rms"]),
    }


# ── Coordinate mapping ────────────────────────────────────────────────────────

def map_to_plane(
    pixel_point: Tuple[float, float],
    H: np.ndarray,
) -> Tuple[float, float]:
    """
    Apply a homography matrix to map a pixel coordinate to plane mm coordinates.

    Parameters
    ----------
    pixel_point : (u, v) in undistorted pixel space
    H           : 3×3 homography matrix (pixel → plane mm)

    Returns
    -------
    (x, y) in plane mm coords
    """
    pt  = np.array([[[pixel_point[0], pixel_point[1]]]], dtype=np.float32)
    out = cv2.perspectiveTransform(pt, H)
    return (float(out[0][0][0]), float(out[0][0][1]))


# ── Debug overlay ─────────────────────────────────────────────────────────────

def draw_debug_overlay(
    frame1, frame2,
    det1, det2,
    pt1, pt2,
    fused, smoothed,
    fps: float,
) -> np.ndarray:
    """
    Compose a debug view:
    - Left half:  Camera 1 frame with mask overlay and detected centroid
    - Right half: Camera 2 frame with mask overlay and detected centroid
    - Bottom bar: fusion source, confidence, smoothed plane coord, FPS

    Returns a single BGR image.
    """
    h, w = frame1.shape[:2]

    # Convert masks to 3-channel for display
    mask1_rgb = cv2.cvtColor(det1.mask, cv2.COLOR_GRAY2BGR)
    mask2_rgb = cv2.cvtColor(det2.mask, cv2.COLOR_GRAY2BGR)

    # Blend mask over frame at 40% opacity
    overlay1  = cv2.addWeighted(frame1, 0.6, mask1_rgb, 0.4, 0)
    overlay2  = cv2.addWeighted(frame2, 0.6, mask2_rgb, 0.4, 0)

    # Draw detected centroid circles
    for overlay, det, pt, label in [
        (overlay1, det1, pt1, "CAM1"),
        (overlay2, det2, pt2, "CAM2"),
    ]:
        color = (0, 255, 0) if det.pixel_point else (0, 0, 255)
        if det.pixel_point:
            cv2.circle(overlay, (int(det.pixel_point[0]), int(det.pixel_point[1])),
                       8, color, 2)
        conf_text = f"{label}  conf={det.confidence:.2f}  area={det.area:.0f}px²"
        cv2.putText(overlay, conf_text, (10, 30),
                    cv2.FONT_HERSHEY_SIMPLEX, 0.6, (255, 255, 255), 1)

    # Resize to half width for side-by-side display
    half_w    = w // 2
    left_half  = cv2.resize(overlay1, (half_w, h))
    right_half = cv2.resize(overlay2, (half_w, h))
    combined   = np.hstack([left_half, right_half])

    # Status bar
    bar     = np.zeros((50, combined.shape[1], 3), dtype=np.uint8)
    src_col = {"both": (0, 200, 0), "cam1_only": (0, 165, 255),
               "cam2_only": (0, 165, 255), "lost": (0, 0, 200)}
    color   = src_col.get(fused.source, (255, 255, 255))
    status  = (
        f"Source: {fused.source:<10}  "
        f"Conf: {fused.confidence:.2f}  "
        f"Plane: ({smoothed[0]:.1f}, {smoothed[1]:.1f}) mm  "
        f"FPS: {fps:.1f}"
    )
    cv2.putText(bar, status, (10, 33),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, color, 1)

    return np.vstack([combined, bar])


# ── Stroke recording ──────────────────────────────────────────────────────────

class StrokeRecorder:
    """
    Records pen strokes as lists of (x, y, timestamp) tuples.

    Filters out points that haven't moved more than min_move_mm to reduce
    duplicate entries from a stationary or barely-moving pen.
    """

    def __init__(self, min_move_mm: float = 1.0, enabled: bool = True):
        self.min_move_sq     = min_move_mm ** 2   # compare squared distance (faster)
        self.enabled         = enabled
        self.current_stroke  : list = []
        self.all_strokes     : list = []
        self._last_point     = None

    def add_point(self, x: float, y: float):
        if not self.enabled:
            return

        import time
        pt = (x, y, time.time())

        if self._last_point is not None:
            dx = x - self._last_point[0]
            dy = y - self._last_point[1]
            if dx * dx + dy * dy < self.min_move_sq:
                return     # point too close to last — skip

        self.current_stroke.append(pt)
        self._last_point = (x, y)

    def save_stroke(self):
        """Finish the current stroke and start a new one."""
        if self.current_stroke:
            self.all_strokes.append(self.current_stroke.copy())
            self.current_stroke = []
            self._last_point    = None

    def flush(self, path: str):
        """Write all strokes to a JSON file."""
        self.save_stroke()
        out = {
            "strokes": [
                [{"x": p[0], "y": p[1], "t": p[2]} for p in stroke]
                for stroke in self.all_strokes
            ]
        }
        Path(path).parent.mkdir(parents=True, exist_ok=True)
        with open(path, "w") as f:
            json.dump(out, f, indent=2)

## Calibration Guide

Run these two commands once, **with the plane in its final position and both cameras mounted**.

```bash
python calibration/calibrate.py --cam 0 --out calibration/cam1_calibration.npz
python calibration/calibrate.py --cam 1 --out calibration/cam2_calibration.npz
```

### Step 1 — Checkerboard capture (intrinsic calibration)

- Print a 9×6 inner-corner checkerboard and tape it **flat** against the plane surface
- Hold it at 20+ different positions — vary translation, tilt, and rotation
- Cover all areas of the frame, including corners and edges
- Accept a capture only when the overlay turns green (board detected cleanly)
- Target RMS reprojection error < 0.5 px; anything > 1.0 needs more frames

### Step 2 — Corner clicking (homography)

- Remove the checkerboard; the plane should be clean and empty
- The script shows your live undistorted camera feed
- Click the **four corners of the plane** in this exact order:
  1. Top-left
  2. Top-right
  3. Bottom-right
  4. Bottom-left
- If you misclick, restart the script — there is no undo
- The corners should match the `corners_mm` values in `config.yaml` exactly

### Recalibrate when

- Either camera is moved or bumped
- The plane surface is repositioned
- Lighting conditions change significantly (HSV tuning also needed)

## HSV Tuning Guide

The orange detection range in `config.yaml` must be tuned to your exact pen and lighting. Run:

```bash
python tools/hsv_tuner.py --cam 0
```

This opens a window with **six sliders** (H_min, H_max, S_min, S_max, V_min, V_max) and shows the resulting binary mask live. 

**Goal:** Adjust sliders until only the orange pen tip appears **white** and everything else (including the black background) is **black**.

### Tips for a good HSV range

| Problem | Fix |
|---|---|
| Background pixels appear white | Raise V_min — background blacks have low value |
| Tip disappears when hand casts shadow | Lower V_min slightly |
| Skin tone bleeds into mask | Raise S_min — orange is highly saturated, skin is not |
| Tip only partially white | Lower S_min or widen the H range by ±3 |
| Two separate blobs on the tip | Lower morphological kernel size, or widen V range |

## Troubleshooting

**Mask is entirely black (tip never detected)**
- Run `hsv_tuner.py` — the HSV range is almost certainly off for your lighting
- Check that `cam1_index` / `cam2_index` in `config.yaml` are correct
- Verify the camera is actually capturing by printing `frame.shape`

**Large jump in tracked position when pen reappears after occlusion**
- Increase `kalman.measurement_noise` — the filter will trust predictions more
- Increase `kalman.process_noise` — the filter will let velocity grow more freely
- Consider increasing `fusion.min_confidence` to reduce noisy partial detections triggering a correct step

**Detection is jittery even without occlusion**
- Widen the morphological `kernel_size` to 7 — removes more speckle noise
- Increase `kalman.measurement_noise` for heavier smoothing
- Ensure cameras are physically stable — even slight vibration causes centroid noise

**One camera consistently gives wrong plane coordinates**
- Redo the homography calibration step for that camera (`calibrate.py --cam N`)
- Ensure the camera did not move after calibration
- Verify corner click order: top-left → top-right → bottom-right → bottom-left

**Performance is below target FPS**
- Set `roi_cam1` and `roi_cam2` in `config.yaml` to crop frames to the plane area only
- Reduce capture resolution (`width`/`height` in config) — 640×480 is sufficient for most pens
- Disable `show_debug` in config to skip the overlay rendering

**Tip not detected near the edges of the plane**
- Camera angle is too steep at the edges — ensure cameras have a clear view of all corners
- Increase the bounding box of the orange range by ±2 H units — perspective changes apparent hue slightly

## Performance Tips

| Optimisation | Expected gain | Trade-off |
|---|---|---|
| Set `roi_cam1` / `roi_cam2` in config | 2–4× faster detection | Must be large enough to cover full plane view |
| Reduce to 640×480 capture | ~2× faster per frame | Slightly lower centroid precision |
